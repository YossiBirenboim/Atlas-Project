Atlas is a web application that leverages RESTful API requests to dynamically fetch and display detailed information about all countries worldwide. The project offers an interactive user interface where users can explore countries by name, region, or specific attributes.

✨ Features
Fetches real-time data from a public REST API (e.g., REST Countries API)

Displays country details such as:

Name, flag, capital, population, region, subregion, and languages

Interactive and responsive UI built with modern web technologies

Deployed on Netlify and GitHub Pages
